# AllTick API

AllTick provides real-time and historical financial market tick data via REST and WebSocket APIs, covering Forex, stocks (Hong Kong, US), commodities, and cryptocurrencies. Designed for exchanges, developers, quantitative teams, and fintech institutions, offering K-line, latest trade tick, and market depth data with token-based authentication.

## APIs

- **AllTick REST/HTTP Query API** — Token-authenticated HTTP query API for financial market tick data including K-line, trade tick, market depth, and static info. Separate endpoints for stock and for forex/crypto/commodities. (`https://quote.alltick.co`)
- **AllTick WebSocket Streaming API** — Token-authenticated WebSocket streaming API for subscribing to real-time market data. Endpoints: wss://quote.alltick.co/quote-stock-b-ws-api (stock) and wss://quote.alltick.co/quote-b-ws-api (forex/crypto/commodities). (`wss://quote.alltick.co`)
